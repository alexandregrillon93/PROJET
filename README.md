# Muscu Coach Pro

## Publication sur GitHub Pages

Le workflow `.github/workflows/deploy.yml` publie le site statique à chaque push sur `master`.

1. Dans le dépôt GitHub, ouvre **Settings > Pages** puis sélectionne **GitHub Actions** comme source de publication.
2. Pousse les changements sur `master`, ou lance **Deploy to GitHub Pages** depuis l’onglet **Actions**.
3. Le site sera accessible à l’adresse `https://alexandregrillon93.github.io/PROJET/`.

## Installation sur un téléphone

- **iPhone** : ouvre le site dans Safari, touche **Partager**, puis **Sur l’écran d’accueil**.
- **Android** : ouvre le site dans Chrome, puis choisis **Installer l’application** ou **Ajouter à l’écran d’accueil**.

Les données sont conservées dans le navigateur de l’appareil. Pour les transférer d’un appareil à l’autre, utilise les fonctions d’export et d’import de l’application.
